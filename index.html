Quick Start & Help
1. Match the light: Move the scene-light slider until the description matches what you see. A general recommendation appears immediately.
2. Get your settings: Use the recommended ISO, aperture, and shutter, or open Alternatives.
3. Refine if you want: Open Gear and/or Creative Intent in any order. Neither is required.
4. More Tools: Open the specialized tools only when you need them.
Tips:
  • The real-world light description is the easiest way to set scene brightness; EV is shown alongside it so you learn the relationship naturally.
  • Tap Match camera meter if you want the slider to match a reflected reading from your camera.
  • Use Copy to save or send your settings.
  • All controls work on desktop and mobile. Use keyboard for fast navigation.
For more help, see the About section or contact the developer.

About This App
Photography Exposure App
Version 4.4.0 — September 2026

This tool helps photographers quickly determine optimal camera settings for any scene, balancing light, creative intent, and film/camera gear. All calculations run locally in your browser. No data is sent or stored externally.
